# brain-todo — 一键处理待办（双模式：标准分流 / 目标模式多轮自动）

## 触发

**标准模式**（默认）：
- `/todo`
- 「处理待办」/「一键待办」/「清 TODO」/「待办分流」/「TODO 大扫除」

**目标模式**（v2.0 · 显式触发，无目标语义一律走标准模式）：
- `/todo 目标 "..."` / `/todo 目标 …`
- 带**明确结束条件**的口头目标句式：「目标：清完所有 C 类」「自动清到 TODO ≤ 15 条」「把 08-15 前到期的窗口都消掉」「能自动清的都清掉」等

## 本 skill 要堵的九个坑（军规 · 每条都有出处）

| # | 军规 | 出处 |
|---|------|------|
| M1 | **不凭印象**：每条待办必现核盘上现状，禁「我记得它做完了/还没做」 | G-X111 · G-X101 |
| M2 | **诊断不是结论**：待办里写的「原因/解法」只是上一场的诊断，标 B 类时须重盘，不继承 | G-X111 追记（08-01 四失败面案） |
| M3 | **落盘前重读 + Edit 不 Write**：TODO.md 是多会话高频共写枢纽，整文件覆写会静默吞掉别人的改动 | G-X107 |
| M4 | **计数现读现数**：报「共 N 条」前当场重数，不沿用会话早段快照 | G-X107④ |
| M5 | **不代 Doctor 打勾**：只有 Doctor 明确勾定才代记留痕（**v2.0 限定放宽**：目标模式下 A 类证据硬条目可代勾，判据与留痕见「目标模式授权」节；其余一切勾项仍归 Doctor）；AskUserQuestion 选项 label 尾部钉（推荐/不推荐） | G-X4 · G-X136 · brain-save v3.3 |
| M6 | **引用条目先看状态行**：待办引用的 GOTCHAS/issue/checkpoint 条目，先读 open/closed 再当依据 | G-X12 |
| M7 | **时钟先对表**：Step 0 必跑 `date`，跨日会话不得沿用起手时间锚；dated 窗口以实跑日期判 | G-X100 |
| M8 | **目标模式动手前先快照**：开工快照 + 逐文件快照，无快照不动手；动作效果无法以文件快照留档的，不进自动执行圈 | 2026-08-09 升级 Doctor 命题「不删除，留档，可回退」 |
| M9 | **双审不过即回退**：双 subagent 对照审查任一异议 → 立即用快照回退该动作 + 条目降级待 Doctor 裁，不强行通过、不当轮重试 | 2026-08-09 升级 Doctor 命题「双subagent对照审查」 |
| M10 | **D 类命令直贴**：凡需 Doctor 终端跑的命令（git / rmdir / rsync / 脚本），/todo 报告里直接构造 `bash` 块贴出（可复制即跑 · 全具体路径零占位符），不写「待 Doctor 终端」空话；命令需先查仓况/路径才能构造的，先查（ls/cat .git/ 纯文本、ls 文件）再贴，查不出写「待查构造＋缺什么」 | 2026-08-12 Doctor 立 |

## 长期授权（2026-08-03 · Doctor 立 · v1.2.1 · 标准模式适用）

> **「以后执行 /todo 的时候，默认批准你动手消掉能消的。」**——v1.1 边界：小快灵直接消，大活单列批。
> **v1.2 补充（同日 Doctor 定）**：「自己消完小快灵，等我做的开问题问我（给推荐）；然后打勾消的时候，开问题让我勾。」
> **v1.2.1 补充（同日 Doctor 定）**：「打勾…可以统一问我要授权」——勾项不分组问，每轮把**全部拟勾清单**（A 类 + 小快灵已消 + 其他勾项）合并成**一道统一授权问题**（全勾[推荐] / 逐条挑 / 都不勾），一次裁完。

- **默认批准圈（小快灵）**：C 类中**单仓、可逆、不删文件 / 不改调度 / 不动数据库写、单场 /todo 内能完成**的条目。Step 3 报告里列出「本轮将消」清单后**直接执行**，做完报 diff。
- **打勾不开绿灯（G-X4 不变）**：小快灵消完 ≠ 自动勾——全部拟勾条目合并一道统一授权问题请 Doctor 裁。执行默认批准，验收归 Doctor。
- **D 类不再只归拢，要开问题问（给推荐）**：等您做的条目按主题打包上 AskUserQuestion（每轮最多 4 题、按优先级取，label 尾部钉推荐/不推荐），能当场裁的当场裁，裁不了的才留「等您」清单。
- **不在圈内（大活）**：多文件 / 跨小时 / 高风险（如渊图畸形节点还原、补写系统概览）——仍走 Step 4 单列请您批专场。
- **永远不在授权内**：D 类的终端/外部系统动作本身（只问不代做）· 改既有资产的大改写（仍 propose-then-confirm）· 删文件（可逆优先，弃用改 `_DEPRECATED_`）。
- 授权只覆盖「**做**」，不覆盖「**怎么做的验收**」——每条执行完仍带「核了什么 / 有什么隐患」两问。

## 目标模式授权（v2.0 · 2026-08-09 Doctor 立 · 四项裁定全照推荐项）

> Doctor 六项升级命题：「减少人在环节；多轮自动处理能处理的环节；目标模式；双subagent对照审查；不删除，留档，可回退；fuxi-station 为大文件备份目录。」
> 四项裁定（AskUserQuestion 全照推荐项）：① A 类证据硬可代勾（G-X4 限定放宽）② 双审全量批量覆盖 ③ 目标模式显式触发 ④ 大文件 >50MB 或批次清理 → fuxi 新子目录。

- **自动执行圈（目标模式限定 · 仅限文档类可快照动作）**：
  1. **A 类证据硬 → 代勾迁档**（G-X4 演进路径首落地，见通用教训 G-X136）；
  2. **C 类小快灵 → 执行**（圈界同 v1.2.1：单仓、可逆、不删文件/不改调度/不动数据库写）；
  3. **目标范围内漏挂 → 自动补挂**（留痕）。
- **「证据硬」判据**（代勾的唯一门槛）：盘上可**机器复核**——文件已改（内容/diff 在）、命令已跑（产物在）、问题已消失（报错不再现）。CC 写不出一行可复核证据 = 证据不硬 = 该勾项归 Doctor。
- **代勾留痕格式**：`（Doctor 2026-08-09 目标模式授权代勾 · CC 代记留痕 · 证据：{一行可复核证据}）`
- **判断性勾项仍归 Doctor**：证据不硬 / 需裁量 / 子项收口但父条目仍开 → 一律攒末批打包题。
- **机器验收层 = 双 subagent 对照审查**：授权只覆盖「做」，验收靠双审（独立重验、不喂结论）+ Doctor 末报抽查，不靠 CC 自觉。
- **永不自动清单（两种模式共用）**：删文件（弃用只走 `archived/_DEPRECATED_`）· 改调度 · 数据库写 · 活班 prompt / watchlist 等活系统配置 · 任何 git 子命令 · fuxi 远端删除 · 改既有资产大改写（propose-then-confirm）· D 类外部动作本身 · **目标范围外条目的处置**（只列报，不动）。

## 执行步骤（标准模式 · v1.2.1 原流程）

### Step 0 · 对表 + 全文重读（每次必做）

```bash
date
cat ~/Documents/Claude/brain/TODO.md
```

- 记下实跑日期时间（M7），后面所有「窗口过没过」「挂了几天」都按它算。
- TODO.md **整篇现读**（M3/M4），不凭本会话早前的印象。

### Step 1 · 漏挂对账（默认窗 = 最近 7 天）

```bash
# ⚠ 窗口按【文件名日期】圈，禁按 mtime——mtime 会被后期编辑/搬迁污染。
# （2026-08-03 干跑实证：mtime 圈 7 天误拉进 07-06 的老日志共 51 篇；按名圈才是真实会话窗。）
CUTOFF=$(date -d "7 days ago" +%F 2>/dev/null || date -v-7d +%F)
cd ~/Documents/Claude/brain/logs
find . -name "2026-*.md" | while read -r f; do
  b=$(basename "$f")
  [[ "${b:0:10}" > "$CUTOFF" || "${b:0:10}" == "$CUTOFF" ]] && echo "$f"
done
# 逐篇抽遗留段条目：
#   sed -n '/## 遗留/,/^## /p' <file> | grep "^- \[ \]"
```

对 7 天窗内每篇日志的「遗留问题 / 待办」段：

1. 抽出每条遗留项；
2. 在 TODO.md 里找对应条目（按主题词匹配，不要求字面一致）；
3. **找不到的 → 漏挂候选**，记一行：来源日志 + 原文摘要 + 挂了几天。

> 出自「日本的诚」案（2026-07-30 补挂注记）：待办只留在日志里、从未进 TODO.md，之后每次 `/resume` 都拿不到，裸放 9 天。本步就是堵这个。
>
> ⚠ 漏挂候选≠该补挂：有的项后续场次已做掉（G-X56），有的本就是「Doctor 动作余项」长期挂账。一律进 Step 3 报告让 Doctor 裁，不擅自补（**目标模式下**：目标范围内漏挂自动补挂，见 G1）。

### Step 2 · 逐条现核（核心步 · 一条都不许跳）

对 TODO.md「待办」段**每一条**，读它的正文和「依据」指针，然后**到盘上/系统里核现状**（M1）。判定落入六类之一：

| 类 | 判据 | 处置建议 |
|---|------|---------|
| **A · 已做未勾** | 盘上证据显示已做完（文件已改/命令已跑/问题已消失），条目还挂着 `- [ ]` | 提议勾掉 + 迁归档，**附证据一行** |
| **B · 前提失效/诊断存疑** | 重核发现条目写的诊断/前提与现状不符；或条目写的是「补 X」（含解法）而非「查 Y」（含现象）——M2 判别信号 | 提议改写条目或标「执行前须重盘」，**写明哪句诊断与现状不符** |
| **C · 仍 open，CC 可执行** | 现状确认未做，且动作在沙箱能力内 | 拆两档：**小快灵**（合长期授权圈 → 本轮直接消）/ **大活**（单列请批专场） |
| **D · Doctor 动作** | 需 Doctor 终端/拍板/外部系统操作 | 按主题打包上 AskUserQuestion（给推荐 · 每轮最多 4 题） |
| **E · dated 窗口** | 含明确日期锚（观察窗/会议/到期日） | 窗口已过 → 提议处置；窗口未过 → 报倒计时 |
| **F · 二手名单/数字** | 条目正文引用某个名单/计数/路径当事实 | 标「引用前重取」（G-X112⑦），如当场重取发现已漂移 → 升级 B |

- 每条判定**必须带一行「核了什么」**：读了哪个文件、跑了哪条命令、看到什么。写不出 = 没核，降级为「未核，勿据本条下结论」。
- 一条可同时属多类（如 D+E），报告里主类在前。
- M6：依据指向 GOTCHAS/checkpoint 的，先读那条的状态行。

### Step 3 · 分流报告（只报告，不动盘）

```
**TODO 分流体检**（实跑 {date} · 待办现数 N 条 · 漏挂候选 M 条）

**A · 已做未勾（k 条）** — 建议勾掉迁归档：
- {条目} — 证据：{核了什么、看到什么}

**B · 前提失效/诊断存疑（k 条）** — 建议改写/重盘：
- {条目} — 哪句诊断与现状不符：…

**C · CC 可执行（k 条）** — 小快灵 {n} 条本轮直接消 / 大活 {m} 条请批专场：
- {条目} — 【将消】动作：…（长期授权 · 做完报 diff · 打勾并入统一授权题）
- {条目} — 【大活】动作：…（请批专场）

**D · 等您（k 条）** — 按主题打包上问题（给推荐 · 每轮最多 4 题）：
- {条目} — 需要的动作：…（**凡有具体终端命令 → 当场构造 bash 块贴出，可复制即跑，M10**）

**E · dated 窗口（k 条）**：
- {条目} — 窗口 {日期}，{已过期 X 天 / 还剩 X 天}

**F · 二手名单待重取（k 条）**：
- {条目} — 引用的名单/数字：…

**漏挂候选（M 条）** — 散在日志没进 TODO：
- {来源日志}：{摘要}（挂了 N 天）
```

### Step 3.5 · 问答板（大型对齐页 · 2026-08-11 Doctor 立 · v2.1；2026-08-12 正名并独立成通用 skill）

**触发**：Step 3 分流后，需 Doctor 拍板的题（D 类＋勾项＋漏挂＋B 类改写＋E 类处置等全部裁定项）**> 4 题**（AskUserQuestion 一轮上限）→ 出**问答板**（单文件 HTML 对齐页），**替代多轮 AskUserQuestion 马拉松**。≤4 题仍走 Step 4 轻量问句，不出页。（阈值与答题回路均 Doctor 2026-08-11 裁：>4 题才出 · 勾选+复制答案串。）

**本步 = 通用 skill「问答板」（`.skills/问答板/`）的 /todo 特化应用。** 页面规约（暖色单文件 / 每题一卡 / 吸顶复制答案串）、文件名 `问答板_{YYYY-MM-DD-HHmm}.html`、答题回路细则**以独立 skill 为唯一定义**，此处不重复以免两处漂移；下面只留 /todo 特有衔接口。

**/todo 衔接口**：
- 卡片内容取 /todo 语境：问题 + **TODO 原条摘要** + 现核证据一行 + CC 建议（选项钉推荐/不推荐；单选 radio、多选 checkbox，推荐项预选中）。
- 落点：outputs → `present_files` 卡片直开（一次性快照、不覆盖旧页、留档可回退）；页尾附「未挤进本轮的留挂项」+ 生成时间戳 + 条数。**不做成常驻 artifact**。
- Doctor 回贴答案串 → 按 /todo 执行面纪律照单执行（长期授权圈 / 勾项统一授权 / Edit 落盘 / 快照 / 守恒自验）→ 末报逐条对账「答案串 → 动作」。**解析不出或缺题 → 缺项重问，不猜、不默认。**

**边界**：问答板只是「问法」升级，**不扩权**——永不自动清单、G-X4 勾项归 Doctor、大活专场批、两问自检，一字不改。

### Step 4 · Doctor 裁定（AskUserQuestion · 分组问）

- **>4 题先走 Step 3.5 问答板**：答案串回贴后本步按串执行；答案串里勾项题的「全勾」即 v1.2.1 统一授权，不再补问。

- **C 类小快灵不问**（长期授权覆盖）：Step 3 报告列「将消」清单即视为已授权，直接进 Step 5 执行。Doctor 当场喊停任何一条即从清单剔除。
- **小快灵消完后，打勾要问（v1.2）且统一问（v1.2.1）**：执行完报 diff → 全部拟勾销条目（A 类 + 小快灵 + 其他）**合并成一道** AskUserQuestion 请 Doctor 统一授权——执行默认批准，打勾归 Doctor（G-X4）。
- **D 类要开问题问（v1.2 · 给推荐）**：按主题打包上 AskUserQuestion，**每轮最多 4 题、按优先级取**（剩下的留「等您」清单下轮再问）；能当场裁的当场裁，裁不了才留。**命令已在 Step 3 报告贴出（M10），Doctor 复制即跑；没贴的写明「待查构造＋缺什么」。**
- 其余按类分组上 AskUserQuestion，**不逐条轰炸**；同类条目打包成一题。
- 选项 label 尾部钉（推荐/不推荐）（M5）。
- 典型问法：
  - **勾项统一授权（v1.2.1 · 每轮只此一题）**：「拟勾清单 k 条（A 类 + 小快灵已消 + 其他），统一授权？」——选项：全勾（如证据都硬则推荐）/ 逐条挑 / 都不勾
  - B 类：「这几条按建议改写？」——选项：照改 / 改法调整 / 维持原样
  - C 类大活：「这几条开专场？」——选项：开（指定哪条先）/ 暂缓
  - D 类：按主题打包，如「终端三件今晚能跑吗？」——选项：能跑（推荐顺序）/ 只跑某件 / 都不跑
  - 漏挂：「漏挂候选补挂进 TODO？」——选项：全补 / 挑着补 / 都不补
- Doctor 会话中口头勾定的，代记留痕格式照 v3.1 惯例：`（Doctor YYYY-MM-DD 口头勾定，CC 代记留痕并迁档）`；长期授权执行后勾销的用 `（Doctor YYYY-MM-DD 勾定 · CC 依 2026-08-03 长期授权执行并留痕）`。

### Step 5 · 落盘（批准后才动 · M3 全程）

1. **动手前再整读一遍 TODO.md**（防裁定期间他场改写）；
2. 一律 **Edit 精确串替换**，禁 Write 整文件覆写；
3. 勾掉的条目**整块迁** `references/TODO-已完成归档.md`「## 已完成」段顶部，正文一字不改，仅 `- [ ]` → `- [x]` + 留痕句（v3.1 完成即迁，别就地留着）；
4. 补挂项追加到「## 待办」段尾部，带 `（YYYY-MM-DD 由 /todo 漏挂对账补挂 · 源：{日志名}）`；
5. 改完回读 diff 自验：条数守恒（勾出=迁入，补挂=新增），无整段误伤。
6. **不跑任何 git 子命令**（沙箱硬约束）；需要提交时构造命令贴给 Doctor 终端。

### Step 6 · 两问自检 + 回报（G-X119）

回报里**显式**答两问，不许省：

1. **核过没有**——本轮实际现核了哪几条、各看到什么；哪几条没核到（写明「未核」）。
2. **有什么隐患**——主动列至少一个失败模式（例：某条 A 类证据只是间接推断；漏挂窗只有 7 天，更早的漏挂不在本轮视野；B 类改写建议本身也可能带本场的新误判）。

## 目标模式流程（v2.0 新增 · 显式触发才进）

### G0 · 对表 + 目标解析 + 开工快照

1. `date`（M7）+ TODO.md 整篇现读（M3/M4）。
2. **目标解析**：把 Doctor 的目标句解析成**可判定的结束条件**——范围（全量 / 某类别 / 某主题词 / 某日期窗）+ 达标判据（如「C 类清零」「待办 ≤ N 条」「某窗口全消」）。**解析不出明确结束条件 → 不进目标模式**：降级回标准模式，并把歧义点问 Doctor——目标模式不猜目标。
3. **开工快照（M8）**：

```bash
mkdir -p ~/Documents/Claude/brain/backups/todo-auto
TS=$(date +%F-%H%M)
cp ~/Documents/Claude/brain/TODO.md ~/Documents/Claude/brain/backups/todo-auto/${TS}_TODO.md
cp ~/Documents/Claude/brain/references/TODO-已完成归档.md ~/Documents/Claude/brain/backups/todo-auto/${TS}_TODO-已完成归档.md
```

4. **回退清单开篇**：`logs/checkpoints/{date}_todo目标模式_回退清单.md`——写入目标原文、解析出的结束条件、开工快照路径、轮上限。此后每改动一行记录（格式见「留档与回退」节）。

### G1 · 多轮自动循环（默认上限 3 轮 · Doctor 可当场改）

每轮依次：

1. **漏挂对账**（同 Step 1 窗口与做法）→ **目标范围内**漏挂自动补挂（留痕：`（YYYY-MM-DD 目标模式补挂 · 源：{日志名}）`）；范围外漏挂只列末报，不动。
2. **范围内逐条现核 → 六类分流**（判据同 Step 2；范围外条目跳过现核，只计数列报）。
3. **自动执行圈**（自动圈内三类动作）：
   - 每动一个文件**先快照**（M8）：`cp {文件} backups/todo-auto/{TS}_{文件名}`；同轮重复动同一文件，首个快照保留即可；回退清单逐行记「时间 · 文件 · 动作 · 快照路径 · 回退方法」。
   - A 类证据硬 → 代勾 + 整块迁归档（留痕格式见「目标模式授权」节）；
   - C 类小快灵 → 执行（做完记 diff 摘要）；
   - 范围内漏挂 → 补挂。
4. **双 subagent 批量对照审查（每轮一次 · 两路并行 · 全量覆盖 · 全不喂结论）**：
   - 两路输入相同：本轮动作清单（条目 / 动作 / 证据原文 / 快照路径 / diff 摘要）+ 相关原始材料指针（文件路径、命令）；**只给原始材料，不给 CC 的分流结论与「我认为」**——两路各自独立下结论（渊图 06-28 三路独立对账范式的双路版）。
   - **agent-A「证据真实性」**：逐条盘上重验「证据硬」断言——文件真的改了吗、产物真的在吗、问题真的消失了吗。输出逐条 通过/异议 + 理由。
   - **agent-B「安全可逆」**：逐条审——可逆吗、越权吗（撞永不自动清单 / 越出目标范围）、副作用面、快照足够回退吗。输出逐条 通过/异议 + 理由。
   - **裁断（M9）**：两路一致通过 → 保留；**任一异议 → 该动作立即用快照回退**（回退清单标「已回退」），条目降级进末批待 Doctor 裁，本轮不重试。
5. **目标判定**：结束条件达成 → 出循环；本轮处理 0 条（fixpoint）→ 出循环；撞轮上限 → 出循环（末报附续跑建议）；否则回 1 进下一轮。

### G2 · 末报 + 一道打包裁定（目标模式全程唯一打扰点）

- **已自动处理清单**：每条 = 动作 + 证据一行 + 快照位。
- **双审结果**：通过 N 条 / 异议回退 M 条（各附两路结论摘要）。
- **待裁打包 AskUserQuestion**（最多 4 题、按优先级取，超出留「等您」清单）：D 类 + 大活 + 双审异议降级项 + 判断性勾项 + 范围外漏挂。label 尾部钉（推荐/不推荐）。
- **回退清单路径** + 抽查指引（Doctor 可按清单逐条复核代勾项，发现错勾 → 按清单回退方法一条还原）。

### G3 · 落盘纪律

同标准模式 Step 5 全条（动手前重读 / Edit 不 Write / 条数守恒自验 / 零 git 子命令），另加：末批裁定结果回填回退清单收尾。

### G4 · 两问自检 + 回报

同 Step 6 两问，另须显式答：**双审覆盖率**（自动圈动作 100% 过双审为达标，逐条列过/异议）、范围外哪几条未核（写明「未核」）。

## 留档与回退（v2.0 · 不删除 · 留档 · 可回退）

- **本地快照**：`brain/backups/todo-auto/{YYYY-MM-DD-HHmm}_{文件名}`——本地回退件，**不进 commit**（先探后加纪律天然排除；想长期留档须 Doctor 另批）。
- **回退清单**：`brain/logs/checkpoints/{date}_todo目标模式_回退清单.md`，每改动一行：
  `{时间} · {文件} · {动作} · {快照路径} · {回退方法（cp 快照还原 / Edit 反串）}`；已回退的标「已回退」。
- **零删除**：弃用一律 `archived/` 或 `_DEPRECATED_` 改名；勾销迁归档（v3.1 既有）；回退 = 快照还原，任何版本都不消失。

## fuxi-station 大文件备份（v2.0 · Doctor 2026-08-09 立）

- **触发阈值**：单次备份产物 **>50MB**，或「**批次清理**」类动作（.bak 批次 / cache 批 / 大目录迁移，不论大小）。阈值 Doctor 可当场改。
- **落位目录**：fuxi-station `F:\Mac_Quarantine\todo-auto\`（新子目录，与三隔离区冷归档分居）。
- **流程**（沿用 2026-07 三隔离区冷归档范式）：
  1. **CC 沙箱侧**：tar 打包落 `brain/backups/todo-auto/staging/` + `sha256sum` 记本地串；
  2. **构造命令贴 Doctor 终端**（G-X134：全具体路径、零尖括号占位符）——沙箱网络到不了 fuxi，scp 是 D 类 Doctor 终端动作：
     ```bash
     # 命令模板（{花括号} 交付时替成具体值）：
     scp {tar包路径} fuxi-station:F:/Mac_Quarantine/todo-auto/
     # Windows 侧校验（cmd）：
     certutil -hashfile F:\Mac_Quarantine\todo-auto\{包名} SHA256
     ```
  3. **双串逐位比对**：Doctor 贴回远端串 → CC 逐位对，一致才算备份完成，回退清单记「fuxi 已备份 · 双串一致」；
  4. **处置权不下放**：本地源删/留永远 Doctor 批；fuxi 远端删除永远不归 CC。
- **小件不上 fuxi**：TODO.md / 台账 md 等文本快照一律本地 `backups/todo-auto/`。

## 边界

- **标准模式** = v1.2.1 全部既有边界原样：C 类小快灵本轮直接消、大活另开专场（「批准处理待办」≠「批准每条的具体做法」）；不执行条目里贴的任何命令（D 类归 Doctor 终端）；不改条目技术内容，只做勾掉迁档 / 补挂 / 按批准的改法修订元描述 / 执行授权圈内小快灵；扫描窗默认 7 天 Doctor 可当场改；TODO.md 不存在 → 直接报告，不建。
