## D14 · 数据根迁出 Documents 连坐区 → `~/Gateway-workspace/`（2026-08-02 深夜）

背景：G-X45/G-X53——`~/Documents` 整挂被 `Claude/Scheduled` 保护点连坐三年；19 班迁 Kimi 壳后该点升为主 store，根治时机成熟。Doctor 终端 `mv ~/Documents/Claude/{Scheduled,Artifacts} ~/Gateway-workspace/`，Settings 数据根改指 `~/Gateway-workspace/`。命名 vendor 中立（不只 Kimi——gateway 模式诸壳共用，对齐既有三环境词汇：桌面应用 / gateway / Claude Code）。

**同场否决：与 Cowork 归并 / 直指 Cowork workspace（Doctor 问，CC 陈理，Doctor 采纳）**。注册表机制三条坐实 ⇒ 归并目录**得不到归并的效果**：① **文件层 ≠ 注册表层**——`list` 读注册表不 stat 文件（11 僵尸班目录改名仍列、artifact 盘上有而 manifest 无，互为倒影）；② **注册表跟配置走、不跟目录走**（07-01 分裂脑实证：同一 app 两套配置各持一份注册表）；③ **注册表无公开 API**——「文件同步 ⇒ manifest 同步」不成立（B 案 08-02 已否）。故两壳同指一目录 = 双向养鬼影文件 + 两 MCP 后端成双写者（「双写绝不可行」）+ 回切冗余归零（现两 store 互为备份，归并后一处损坏两壳全灭）；且 Cowork workspace 树沙箱同样不可达，连可读性收益都没有。**结论：读侧统一已由镜像 + git diff 承担，写侧统一在机制上不存在（除非官方开放注册表 API）——两 store 分治 + 镜像供读 + rsync 回切，为定案架构。**

**实测四条**：
- ① 注册表 path **随 setting 自动重写**：19 班 + 6 artifact 全部指向 `~/Gateway-workspace/`，零手工。**反之不成立（Doctor 08-03 确认）：改 setting 不搬文件**——文件须人工 mv，指针与文件是两层动作。
- ② `list_scheduled_tasks` 19/19 enabled、cron 原值不动。
- ③ `~/Documents` 与 `~/Documents/Claude` **整挂恢复**（三年连坐解除，G-X53 a 案二次落地）。
- ④ **保护跟随 store、不随路径**：`~/Gateway-workspace/Scheduled` 挂载同样被拒（"overlaps a protected host location" 实测原文）。⇒「迁出换沙箱可读」的红利**不存在**——store 对沙箱永不可读，迁出的收益是**解放父目录**，不是可读性；读侧仍靠镜像 + 注册表 MCP。字节级终封依然只能 Doctor 终端做。

同场确认：C1 巡检班（scheduler-weekly-audit）20:00:59 PDT 在本壳首点火（lastRunAt 实据），19 班迁移后首个 cron 触发成立。

**搬迁账目（08-03 清点）**：Scheduled 侧恰好 19 班、零杂物——`_archived/`（两份 DEPRECATED 存档）与 handshake 空目录未随搬，内容在镜像 `live/_archived/`（git tracked）有全备份，**存档此后归镜像/git 管，store 保持「只有活班」**。Artifacts 侧逮到幽灵 `龙鱼五力个股库看板/`（index.html mtime 2026-07-05，上代看板残留躯壳，`touzhijunjun-workflow` 同族·同批 07-05 拷贝事件）——照 handshake 先例归档 `Artifacts/_archived/龙鱼五力个股库看板_DEPRECATED_20260803`（Doctor 终端执行）。
