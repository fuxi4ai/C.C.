## 脊柱

**Σ 机械因子 ＋ 残差 ≡ 实际指数（逐日闭合，残差兜底）**。曲线为累计路径：逐日恒等成立 ⇒ 累计恒等成立。

- 实际指数＝SPY 日收益（attribution.db 日线表库值，02-20 起，覆盖三时段）。
- 残差＝当日 SPY 实际 − Σ 可判因子。**残差吸收一切判不了/没注册的**——恒等式在数值上恒成立，不闭合的是覆盖面（与台账同一口径哲学）。

| 因子 | 触发窗（events 表映射） | 机械签名（全满足才命中） | 量级取值 | 可判性 |
|---|---|---|---|---|
| **ƒ·央行规则不确定性** | type=FOMC／央行官语 当日＋次日（余震型） | DGS10↑ 且 DGS2↓ 且 (10Y−2Y) 利差 Δ≥**+10bp** ＋ VIX 日 Δ≥**+5%** | 带中值 **−1.1pp**（注册带 −0.8~−1.4） | ✅ |

## 表结构

```
factor_daily_backtest(
  trade_date TEXT,        -- YYYY-MM-DD
  factor     TEXT,        -- 因子注册名
  contribution_pp REAL,   -- 当日量级（pp，符号含方向）
  detail     TEXT,        -- 命中签名明细 JSON（各分项实测值）
  source     TEXT='mech_v0',
  asof       TEXT,        -- 计算时间戳
  PRIMARY KEY (trade_date, factor, source)
)
```

幂等：`source='mech_v0'` 行整体 DELETE+INSERT 单事务重建（不动他表他 source）；写库走 SQLite 协议（停写窗口＋backup API 快照＋原子替换），**Mac 原生侧跑，沙箱不直写**（G019／写库裁定）。
