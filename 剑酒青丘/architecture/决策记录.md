1. **v6/v7 两轮独立验收 fail-closed、v9 才定稿 PASS（组件级）**：v6 阻断=索引漂移（被审资产验收期间被并发修改）+ --execute 错误族失真；v7 阻断=--execute 缺陷现役 + 权限位未核 + G-007 过时文案 + current_entries 字段指历史 v3。v9 修复四项（--execute 仅在跨过 commit 点后才可报 post-commit 失败；字段拆分 historical_phase1_delivery_index_v3_entries / current_delivery_index_v9_full_readback；G-007/G-010 文案；G-013/014/015 已立），权限硬门由 Doctor Mac 侧全量 os.lstat 318 条闭环。v6/v7/v8 均留 immutable superseded 证据。理由：错误族失真、语义漂移、证据不足逐项阻断；每轮修复后重验。
2. **班 glob 选择器 = 结构性治理缺陷 → selector exact pin**：glob「最新日期版」绕过 CURRENT_SHA256SUMS，任何日期更新但未 attest 的 registry 会被自动消费（A 单实证：昨晚 input_identity=fb80b4eb 坐实规则被执行）。修复=resolve_registry_from_manifest.py（禁 glob、exact pin 五重 path/SHA/bytes/rows/schema+双 SHA、manifest 44 项全树校验、同日/更新版冲突检测 attested→STALE / unattested→UNATTESTED、零 assert）；班 prompt 失败即停班。**后续 registry/contracts 升版必须同步审批更新 pin，否则 STALE 停班（预期 fail-closed）。**
3. **16 DB digest 重新定性**：attribution.db 由 Codex heartbeat usdjpy-15（「EAL全量采集」06:30/18:30 PT）每日两次合法写库；9bd9a78a 是冻结时点历史快照、非 live DB 恒等式。后续 DB 不变性验收绑定当班 sealed SHA。
4. **地缘市场时钟裁定方法论（post-event loop v1）**：发生时刻 ≠ first-public 源时钟（G-006）；12 条 catalog 边界安全裁定（7 resolved：盘后 3/盘前 2/休市 2/盘中 0 + 5 excluded）；盘前/盘中→当日反应日、盘后/休市→下一交易日，区间跨开盘/收盘/阶段边界非零拒绝；旧 crosswalk 日期回退清零门（fallback_rows=0）；观察性映射 production_registry_eligible=false，不进 registry、不建因果。
5. **职责分离固化**：CC=独立验收方（只读重放+故障注入）、VV/Codex=实施方（thaw/修/升版/重冻结）、Doctor=裁定方。签字按分轨：事务性／事实性的由未参与实施的 subagent 代签；方向性的问 Doctor。**PASS 由未参与实施的审核方出具**；CC 不执行授权单 B 实施。
