# 动手前卡（2026-11-06 脑暴 P4 · 十条最高频通则 · 改既有资产前过一遍，命中即按指针读原条）

1. **引用扫全部出现点**：改一处措辞/编号/路径前先 `grep` 全仓同串列齐再改，改完回扫所在段落（damper 族 1 · G-X111）。
2. **断言「无」前先枚举**：写「没有/不存在/0 条」前贴出检索词与范围，词形同义扩展；枚举＝0 先疑路径错（G-X116 · G-X104）。
3. **YAML 引号与行尾注释**：frontmatter 双引号标量里禁裸反斜杠，值后不写行尾 `#` 注释，写完 `yaml.safe_load` 过一次（G-X187）。
4. **编号先 grep 再写**：G-X / EXP / ERR 新号取 `grep` 现存最大号 +1，引旧号先核其标题再写（G-X101 · brain-save v3.0）。
5. **日期一律横杠 `YYYY-MM-DD`**：跨源比较先归一格式与时区，禁裸字典序比较（G-X144 · G-X181）。
6. **改前读盘核现状**：并发会话共写一仓，Edit 前重读目标段；引自己早前落盘的东西先重探它现在的版本（G-X107 · G-X117）。
7. **计数现读现数**：任何「N 条 / N 个」先跑 `wc -l` / `grep -c` 再写，并写明按什么计（G-X209 · damper 族 3）。
8. **移动/归档文件先扫内部相对链接**：`grep -n '](\.\./\|](\./\|\[\['` 列齐消费端再 mv，旧址留 `MOVED.md` 指针（2026-11-05 alarm 迁移撞车 · 2026-11-06 脑暴 F2）。
9. **改 skill 走发布链**：只改 `brain/.skills/{名}/SKILL.md`，跑 `skill_release.py release`，只上传它列出的 zip；不直改 portable / 账号副本（G-X231 · `.skills/README.md`）。
10. **commit / push 交 Doctor 终端**：沙箱不跑任何 git 子命令，贴命令块、scoped add、先探工作树（G-X97 · G-X83 · ERR-20260718-002）。

> 用法：damper §五「开始」与 brain-save Step 3.5 提案前各过一遍。来源：2026-11-06 金融线脑暴 P4——近三篇日志踩的坑索引里都有、/resume 召回 0/3，故压成一页前置卡。
