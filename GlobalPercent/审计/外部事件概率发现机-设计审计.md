# 审计 ·《重要外部事件概率发现机》v0.1.0

> **被审对象**：`Documents/Codex/2026-07-29/tech-intel-dashboard/docs/external-event-probability-discovery.md`（上传件与磁盘件 diff=0）。
> **审计口径**：对表金融工作流——回测设计七问 / 回测准入机制（G-X94 分级 + 循环移位 Westfall–Young maxT）/ 取数四问（日期/时点/语义/源）/ P-10/P-11 纪律 / GlobalPercent 现状 / 伏羲冷存档协议。
> **审计者**：CC · 2026-07-31（北京晚间场）。本文是建议输入，采纳与否由 Doctor 与 Codex 侧裁定。

**总评**：不变量层（§4）与证据契约（§8/§12）质量很高——预注册、点时、独立事件计数、fail-visible、不编数、口径标注，基本把金融线近两月的教训原生搬进了新域；§19.3 证据分级与置换检验与《回测准入机制》逐字一致。**问题集中在三处 🔴**：§5 工作流锚点一半悬空；pM 数据面零工程设计；资产腿缺口径字段（P-11 病根在新系统的复刻点）。建议修订后再冻结（阶段 0）。

## 一 · 功能性

### F1 🔴 pM 数据面没有工程设计

pP 面规格到了 API 名、字段、采样频率、深度门（§7.1/§17.2/§17.3）；pM 面只有方法论（D/S/R）没有数据源——CME/OIS/期权从哪取、频率、失败退路、缓存陷阱，全部空白。这恰是金融线刚趟过的最难一段：rateprobability 系 OIS 口径且吐过期缓存（已证不可用）、FedWatch 一晚四易其值只能手更。C 层「以 CME/OIS 为主基准」现在是一句没有腿的话。
**建议**：补一节与 pP 对等的 pM 数据面设计；把 `风险日报/fomc_market_exp.json` 的「已证不可用源清单」继承为初始黑名单。

### F2 🟠 A 层 β 会长期 undetermined——结构性后果，不是失败

G3 要求滚动 OOS β，§13.2 一个事件簇只算 n=1，而 A 层（战争/海峡/制裁）独立事件天然稀疏——90 天影子期攒不出 20 簇，边际吸收对 A 层会长期停在 `undetermined`，「新增信息排序」的乘积长期算不出。§12.4 有降级路径，但没把后果写成预期。
**建议**：阶段 3 验收明写「A 层 n 不足 ⇒ 延长影子期是预期路径而非失败」；预注册类别级 β 池化（分层收缩）为唯一允许的增样方式；H5 主战场明确划给事件复发的 C 层宏观。

### F3 🟡 48h 热窗与 3 日观察窗打架

§11.1 要 3 日 Δp，§17.3 本地只留 48h 原始热数据——3 日窗每次都要回冷存档。
**建议**：明确「派生概率序列（去重快照的 p/Δp 序列）本地长期保留，仅原始订单簿走 48h→冷存档」。

### F4 🟡 隔夜假设 H1 缺资产侧配套

验证隔夜 ΔpP 增量需资产侧有隔夜可观测代理（期货/离岸），`asset_reference` 未要求登记；不补则 H1 不可检验。

## 二 · 适配性

### A1 🔴 §5 锚点一半是悬空引用

「三只钟」「七种动作编译」「market_grade」在检索范围内**只出现在本文档自身**；被引为出处的 `ai-market-analysis.md` 实际章节为：定位/三层事实纪律/五档烈度/正交字段/市场有效力道/风险敞口雷达/只读结构先验——没有钟、没有动作编译、没有 market_grade、没有 OOS。整个「送入现有金融工作流」的接口层建在未定义对象上。
**建议**：要么先把三只钟/七动作写进研判协议再冻结本文，要么把 §5 重锚到实际存在的资产。这是 brain 刚清完 25 条悬空链接的同族病，宜在冻结前清掉。
另两处：Risk Daily 锚点指向的 `brain/风险日报/风险日报.md` 是 2026-07-30 为修反链补的 **stub**，非实体资产（实体在 `Projects/风险日报/`）；路径写大写 `Brain`——APFS 不分大小写所以能解析，进 git/Linux 即碎，宜改小写规范路径。

**⚠ 勘误（2026-07-31 · Doctor 纠正 · CC 实地复核确认）**：「三时钟/七态/market_grade 无落盘定义」这一负向结论**错误**。实有落盘定义——`brain/logs/checkpoints/2026-07-17_驾驶舱标签页_PRD.md`（三时钟判定口径 §附·冻结·逐条注来源 ＋ 行动权限七态确定性映射表）、`2026-07-19_驾驶舱接回调级别读数_PRD.md`（`market_grade`＝市场级回调级别读数，与标的级三时钟平级）、`Database/龙鱼-标的分析库/cockpit_data.py` 与 `cockpit_schema.sql`（枚举 CHECK 约束落库）。A1 的正确结论应为「**当前文档错锚**」（v0.1 把出处指向 ai-market-analysis.md 且用了变体词），v0.3.0 已修正锚点并明确定义权归影子驾驶舱。**CC 检索错因**：①拿 v0.1 文档的变体词「三只钟/七种动作」当检索词，落盘正名是「三时钟/(行动权限)七态」——负向断言前没扩同义词形；②全树 grep 超时后缩范围重跑，缩掉的恰是 `checkpoints/`，且未在结论里把「范围缩过」升格为置信度折扣。同 G-X79（负向结论要跨源核实）。

### A2 🔴 资产腿缺口径字段——P-11 病根的复刻点

概率腿有 `probabilityMeasure` 五档，很好；资产腿（`asset_reference`/`asset_response_snapshot`）没有对应字段。同一个「10Y 收盘」2026-07-29 刚在本地库劈过 5bp（P-11 v2 三轴：约15:30 指示性买方报价·插值常年期 vs 16:00 成交收盘·单券指数，见 [[剑酒青丘/frameworks/事件归因台账]] P-11 与 烛照九阴 ERR-20260731-001）；本系统要跨 Polymarket 时间戳对齐利率、商品、外汇的「价格」，每条资产腿都会遇到同样三轴。
**建议**：给资产腿加 `priceBasis`（成交收盘/报价快照/结算价/盘中读数/插值构造）+ 时点语义字段，列为 schema 冻结项。
**⚠ 追注（2026-07-31 晚）**：本节引的「`^TNX` 16:00 收盘」已被同日 0937 场实测推翻——`^TNX` 交易时段 08:20–15:00 ET，收市**早于** `DGS10` 的 ~15:30 报价快照，方向相反（P-11 已升 v3）。A2 结论不受影响，反而多一例：连「收盘时刻」本身都必须进时点轴合同，不能按惯例默认。

### A3 🟢 已核实相符的部分

证据分级（≥20 确证 / 10-19 暂定 / <10 方向）与循环移位 maxT 同《回测准入机制》；GlobalPercent 复用边界、温度≠概率、「测试全绿≠真实校准完成」同其 README/STATUS；伏羲 outbox/SHA-256/原子提交/回执同 `fuxi-archive.md`；「近期回测未证明可机械执行的通用预测因子」同剑酒青丘结论；不交易/不碰钱包同硬约束。

### A4 🟡 常驻采集 vs Mac 在线现实

A 层实时订阅默认 Mac 常开，旅行模式经验说明并非总成立。last-known-good 已覆盖崩溃面，但 OOS 台账需能区分「停机缺口」与「系统弃权」，否则覆盖率会把停机算成弃权——补一个 gap 标记即可。

## 三 · 合理性

### R1 🟢 不变量层扎实

§4 十条不变量、§12.1 的 ΔS 三项分解（Δq / 严重程度 / 定价核）、§10.2 overround 保原值、尾部 Δlogit、favorite-longshot 分层校准、吸收事件才允许期限曲线——都对，多数超出同类设计常见水准。§13.1「时间切分不能消除机械自引用」是全文最硬的一条，保住它。

### R2 🟡 评分需按剩余期限分层

「事件终局不能反推当时计价」写对了；落地时 Brier/log loss 须按**预测时点剩余期限**分层报告（不止 H4 的校准分层），否则长期限合同的评分会系统性冤枉市场。

### R3 🟡 G1 门槛下的现实预期

±2pp 内 $10k 双边深度在非选举类市场不常见，§20 抽样自己也证明多数候选到不了 A 级。不是设计错误（硬门哲学一致），但界面与阶段验收应按「常态＝B/C 级＋纯观察」设计，别按事件卡满配设计。
