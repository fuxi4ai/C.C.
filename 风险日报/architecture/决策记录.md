## 2026-07-25 · 立项 + P0 六决策（brain-prd 四轮对齐）

| 决策 | 理由 | 影响 |
|------|------|------|
| **并行新体系**（不复用五因结构/逻辑） | Doctor 拍板；原子-分子-化合物是独立第一性本体，与五因「触发×环境」不同轴 | 自成一套、不动五因生产；避免两套漂移的代价由「共享工具链不共享图模型」纪律管 |
| **原子从零/一手数据算**，现有风险现象**全重算进原子** | Doctor 选「从零采集」+「现有现象全重算」；不 piping 五因算好的读数 | 8 原子各连一手源（market_data/recap/PEC/alarm）；不并列旧读数（AI-tech 除外） |
| **AI-tech 特例**：保留杀伤指数面板 + 底层信号入「AI科技」原子 | req6 明说整合、且是 Doctor 成品 | 唯一保留旧读数面板者；评分表 + 象限图都嵌，底层 5 轴入原子 |
| **每日快照范式**（非 live） | 本地 db/markdown/artifact 无 MCP connector，live 取不到 | `build_risk_daily.py` 读源→snapshot JSON→内嵌 HTML→`refresh-risk-daily` 任务 `update_artifact` |
| **确证口径按量分档放宽**（取消 <20 硬拒） | Doctor「<20 太严·按数据量放宽」 | ≥20 确证 / 10-19 暂定（可计温·标「中样本」）/ <10 方向真·不确证；用于 P1 化合物回测（详 [[通用教训]] G-X94） |
| **MVP 汇总展示优先·化合物回测=P1** | 从零采集是重工程 vs MVP 要快 | P0 落原子层(温度)+分子层(预警)+AI面板；化合物层结构占位 |

**P0 成色（2026-07-25 首建·独立子 agent 复核通过·无完成幻觉）**：8 原子（油价/汇率/杠杆/新股虹吸/量能/情绪/地缘/AI科技）全部一手源、缺字段 0；综合风险温度 54🟠。**已知边界**：地缘原子＝PEC register 派生粗读（US10Y/GlobalPercent 无数据源，待接真地缘数据源细化）；新股虹吸＝阈值锚定映射（0.045=p95）。

**温度/烈度量纲**：0-100 + 🟢平静(<50)/🟠警戒(50-75)/🔴高危(>75)；口径＝滚动分位（pctile）/ emotion_score / 阈值映射；震动烈度＝|急变|/满标度×100。单一定义于 `build_risk_daily.py` `band()`。

**纪律继承**：`risk_overlay_not_alpha`（非 alpha、不出交易/仓位/方向建议）；化合物回测复用剑酒青丘《回测设计七问》。

**待续**：P1 化合物回测（分子组合对市场差异影响）；地缘数据源细化；PRD 待 Doctor 终审打 ✓。
