## 手工解读层维护（2026-09-11 立 · 2026-09-10 停更 45 天事故沉淀）

卡片分两层，勿混判：**机器数值层**（pain/走势/温度·每日 09:08 PT 班自动刷新·数据在 `data/taco_components.db` 与 market_data.db）与**手工解读层**（`taco_reading.json` 的 regime/note/as_of、`geo_reading.json` 的 phase/note/as_of·手动改文件即生效、无需改码）。

- **诊断**：「某卡很久没更新」先分两层核——机器层查 `taco_components.db` 最新日期与 envelope sources 的 machine 标志；手工层查 reading json 的 mtime/as_of 内嵌键。机器层日更会掩盖手工层停更（2026-09-10 TACO 案：机器值 09-08 vs 手工 07-27 同卡共存 45 天）。
- **更新流程**：改两 json（regime/phase/note 属判断性内容 → Doctor 批草案）→ `python3 build_risk_daily.py` 重跑（沙箱可跑·exit 0）→ dashboard 回读验证 as_of/相位/触发态 → 全报 `data_cutoff.value` 随最旧手工源前移（本次 07-27→08-13）。
- **词表**：geo 五档 escalating / standoff / easing_start / easing_confirmed / resolved → 触发态 fired/near/none（仅 IR-P4 命中时生效）；taco regime 三档 normal / complacent / anti_taco。
- **手工源清单**：taco_reading.json · geo_reading.json · fomc_market_exp.json（CME FedWatch·每会前手更·无免费 API）。任一停更都会拖 data_cutoff。
- PEC register 是读数依据（引用不修改·自有 9-30 中评节奏）。
