# 会话日志 — 2026-07-27（风险项综合回测 R0-R3 + 准入机制 + P0 重构）

**项目**：风险日报 / 剑酒青丘（回测方法论）
**主题**：对接剑酒青丘七问，对全部风险项（原子/分子/化合物）做三轮综合回测；蒸馏出回测准入机制；据发现给风险日报做 P0 诚实标签重构

## 完成的工作

- **R0 基建**：建七问回测台（沙箱临时·不落持久资产）——target=上证综指未来20日最大回撤≤-5%（基率18.5%·2020+多区制）；统一可评/基准同源/独立事件(gap5)/增量(控trail5)/区制。产出可测性矩阵：R担保比例(2012+)/IPO/量能多区制可测，两融/油/US10Y/科技/情绪困在2024+单区制。
- **R1 广度普查**（3路并行agent+红队）：多数存量风险因子无前瞻预警力；唯一存活是**新因子「涨跌停净额breadth(亢奋见顶)」**（71事件·5区制·控行情后1.19）；深化**担保比例R=同步缓冲计非预测器**（强平self-cleaning致崩盘中R反升）；跨资产传导全军覆没（北向反向证伪·CNH数据不足·油事件膨胀）。**抓出数据地基问题**：volume_trillion/max_consecutive/seal_rate 三伪列 + limit_up/down 2026-06量纲断裂。
- **R2 深化**（Doctor三条人类经验反馈：绝对vs相对/适应性衰减/第一性两类可赚）：加**波动调整target(T2照妖镜)**——存活因子绝对lift1.6→T2 0.57失效，**大半是高波动区制代理**；情绪"水平"全过不了T2、唯"退潮拐点(二阶)"扛过；高位缩量被红队走查降级(1.36→1.05·低波动代理)；组合/门控无增量；时间衰减=区制依赖非套利。状态计首盘。
- **R3 严格机制**（Doctor同意六柱机制设计）：**走查规格曲线+循环移位best-of-grid置换检验**——退潮拐点27规格T2中位仅1.03、观测最高1.75落在零分布(中位1.38/95分位1.93)内、**exact p=0.143不显著**。红队独立复核判机制严谨(Westfall-Young maxT)。**结论：无一价格/量能因子过严格机制。** 校准轨：等权综合分U形不校准(逆向量污染)；仅20日波动(AUC0.83)+R缓冲(0.74)作nowcast立得住·零预测；**杠杆/成交额方向用反(高=景气非险)**；**任何机械减仓2020-2026净亏-1.7~-5.0**。
- **固化准入机制**：新建 `剑酒青丘/frameworks/回测准入机制.md`（四道闸：走查/T2照妖镜/best-of-grid置换/增量 + 双轨预测vs状态 + 校准尾部效用目标）。
- **风险日报 P0 诚实标签**（Doctor批P0·P1单独设计pass）：`build_risk_daily.py` hero改"综合脆弱度·同步状态·非预测·勿据此减仓"；加免责横幅(本页=nowcast非预警器·现有因子无一过机制·机械减仓净亏)；分子行"预警"→"同步读数(非预测)"。重跑+推artifact。
- **唯一交付物**：`Projects/风险日报/回测报告/2026-07-27_风险项综合回测_R1.md`（R0-R3全程·三轮独立红队复核）。
