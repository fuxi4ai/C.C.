- **模型 C 重构（源 vs 效应）**：原子＝抽象驱动源、分子＝可观测市场变量（带真实一手数据）；**地缘→油价成模型内正式边**（油价由 地缘 驱动·曾含供给）；综合温度改取分子层均值。
- **co-glow 传导预警**：分子若有驱动原子已触发（🟠/🔴），叠一层驱动带色脉冲外圈环（`::before`·不冲突自身发光）+⚡。
- **纯反推原子清理 + 领先性验证**：外货币紧缩←**US10Y**（先行独立）、内部市场←**情绪周期**（Doctor 裁定）、能源供给**退役归档**；北向资金验证**不领先**（lead-lag 峰值在 k=−1 滞后）→ 退役；情绪周期 emotion_score 也验为强同步(k=0 0.585)非次日领先，但按"相位领先"接入并标注。→ 现 4 驱动原子全有独立信号，反推清零。

## 做出的决策

| 决策 | 原因 | 影响 |
|------|------|------|
| AI-tech 原样整合＝iframe srcdoc + 快照冻结 | 源在 Claude's workspace 沙箱够不着·必须内嵌副本 | 源工具更新需重同步 snapshot；`</`→`<\/` 转义防提前闭合外层 script |
| 模型 C：源=原子 / 可观测=分子（Doctor 选） | 油价是效应非源·地缘→油价该是正式传导边 | 8 原子/8 分子 → 4 原子(驱动)/7 分子(可观测)·油价双驱动后减为地缘 |
| 综合温度取分子层均值 | 原子温度派生自分子·取原子层会重复计 | 综合＝可观测层·50🟠 |
| 驱动原子必须有"先行独立信号"·否则退役 | 反推(effect→source)不是真因果·信号方向反了 | 能源供给无供给数据→退役；US10Y/情绪周期补上 |
| 领先性要用 lead-lag 验证·不拍脑袋 | 北向"独立但不领先"·情绪周期"同步非次日领先" | 北向退役；情绪周期按"相位领先·非次日收益"接入并标注(诚实备查) |
| co-glow 用 ::before 环 | 不与分子自身 band 发光(box-shadow)冲突 | 快通道≈同时·慢通道当领先信号 |
