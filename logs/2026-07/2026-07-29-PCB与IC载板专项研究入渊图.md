## 完成的工作

### 一 · 六问链（每问都先查图谱再答，不凭记忆）

1. **「PCB 在 AI 硬件进步中会不会被淘汰」** → 图谱既有 `concept_PCBSubstrateRelation` 正是为此写的三层框架（结构层纯互补 / 工艺层同源收敛 / 价值层相对替代）。**跳出问题内置的二元**：答案在三层上完全不同。并揪出该节点的**缺失**——它只写了「3D Folding 把重心往载板推一格」这个**单向**判断，而 `product_LPU` 节点里明载反向证据：取消载板后 PCB **20-24 → 40-52 层、单板价值 5-7 倍**。
2. **「载板对比 PCB 先进在哪／多层 PCB 对比载板先进在哪」**（第二问是反向的，把默认排序拆了）→ 从图谱取实参：mSAP 20-40μm、载体铜箔实现 25μm 细线、Q 布价 T 布 3-5 倍、PTFE 做不了粘接片（需 400℃）、M9→M10 材料军备。得出 **XY vs Z 复杂度容器**：载板往细里做、PCB 往大里做，排先进度等于问显微镜与望远镜哪个更先进。
3. **五维对比**（材料/应用/技术细节/卡点/3D 封装适配性）→ 最不对称的是第五维：Intel EMIB-T 须在硅桥内嵌 **DTC 深沟槽电容**「补偿**有机基板高阻抗**带来的电源完整性问题」——载板的物理短板要靠硅侧补救。
4. **加稀缺度量化 + 代表公司 + 相邻结构** → 十一环节 1-10 序数评分（含刻度定义），结论：**高稀缺位几乎全在材料层且多为日本/单一来源**，制造环节最高仅次一档。
5. **「味之素积层膜和积层膜载板有什么区别」** → 膜是材料、载板是器件；关系同 CCL 之于 PCB。**决定性证据＝京瓷技术**：陶瓷核心叠膜可把膜层数 20→2，「**大幅降低对膜的依赖，但并非替代载板**」——若两者是一回事此句不成立。
6. **「AI 核心硬件谁含 PCB／IC 载板」** → 矩阵化，**HBM 是唯一两者都不含的**（被封进别人的载板里）。推论：**HBM 与载板是并列瓶颈不是一条链**，与既有「ABF 与 HBM 同为 2027 年制约」自洽。

### 四 · 副产品：兴森科技第二次订正（63.0 → 61.0）

Doctor 问「兴森是采购膜做载板的么？毛利率多少？」触发深挖，查出三处：

- **新增负面**：`concept_CoWoPCompetitiveLandscape2026` 载明兴森为四家 CoWoP 供应商之一参与 NV 认证、**当前良率 36%、处于末位** → 新赛道落地 3.5→2.5
- **口径修正**：首判引「国内 ABF 厂商 Q2 已全部满产」是**行业口径**，而兴森自身 props 标 `abf_utilization_2026_current=低`（BT 才 94.5% 满产）→ 供需端 18→17
- **理由更换（分不变）**：议价 3.5 的理由从「供给约束型低毛利」改为**业务加权**——载板业务毛利 **37.5%**、公司整体 19.17% 系 PCB 68% + 载板 23% 加权

## 做出的决策

| 决策 | 原因 | 影响 |
|------|------|------|
| **「会不会被淘汰」判为问错了层** | 图谱三层框架显示：系统层不会（物理互补）、主体层不会（取代者是 PCB 厂自己爬上去的）、价值层份额在转移**但方向可逆** | 收束为「PCB 这个词正在失去分析价值，分化在环节内部不在环节之间」，与昨日判分结果自洽（同属 PCB 链，生益 73.0 vs 消费电子导向者 <50） |
| **XY vs Z 复杂度容器立为新节点** | 原三层框架只讲价值份额，没讲**复杂度去了哪**。LPU 证明复杂度不消失、只换维度存放 | 补上了「为何两者先进性不可比」的机制；给 `concept_PCBSubstrateRelation` 打了反向证据补丁 |
| **稀缺度评分只做序数、明标非硬指标** | 随渊图 `metric_ProsperityScore_ICSubstrate` 既有惯例 | 十一档排序 + 刻度定义写进 raw；节点 props 只存排序结论不存分值 |
| **术语区分只入 raw + 节点 props，不单独立节点** | 「ABF 的 F 就是 Film、故『ABF 膜』冗余」是**元知识/表述规范**，非产业事实 | 但顺手修了 `concept_ABFSubstrate` 描述首句（原写「基板**材料**」与其全部 supplies 边指向制造侧矛盾） |
| **HBM 一行明标"据推断、待核"** | 图谱内**无描述 HBM 封装层次的节点**，该行系据 CoWoS 结构推断 | 写进节点 `_note` 与札记待核清单，不冒充图谱既有事实 |
| **主动不加牵强的边** | 新生科技 FCBGA 产线改光模块 UHDI 是好证据，但套进 11 种 schema 都别扭 | 改写进 `concept_ComplexityContainerXYvsZ` 的 desc（守 G-12：宁可少一条边，不要一条语义模糊的边） |
| 兴森下调 63.0→61.0 | 见上「副产品」三处 | 第三次订正（前有江波龙、华大九天） |

## 遗留问题 / 待办

- [ ] **HBM 封装层次专项核实**：图谱缺该节点，本次矩阵里 HBM 一行是推断。若要把「HBM 与载板并列瓶颈」这条推论坐实，需补 HBM 封装结构节点（DRAM die 堆叠 / TSV / base die / micro-bump 直连中介层）。
- [ ] **多业务公司的议价维系统性失真**（本场暴露）：`engine_facts` 只给**公司整体**毛利率，而 RULES §3 要求「占比>10% 的核心业务分别分析后加权」。兴森 PCB 68%＋载板 23% 毛利差一倍；同类结构还有华正、南亚新材、生益电子。**修法建议**：给 claude 腿盲打包补分业务营收/毛利（tushare `fina_mainbz` 有，渊图侧查炬光分部时用过）。
- [ ] **玻璃基板路线仍在流动**：CoPoS「产品线已建成、正在开发迭代」，英特尔 GlassCore 延至 2029，京东方 2026-10 目标量产。真正判定点是未来两年 CoPoS 与 LPU 两条路线各自落地量——这决定复杂度滑块往哪边推。
- [ ] 前场遗留未动：中兴通讯 claude 腿（盲打污染）、港股引擎缺口、59 只判分**尚未刷看板**（需跑 `build_dark_board.py`）。
