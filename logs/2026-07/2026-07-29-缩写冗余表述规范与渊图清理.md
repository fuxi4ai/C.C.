## 完成的工作

### 一 · 从一句纠正到一条规范

- Doctor 在 PCB／载板专项收尾时说「**不要用简写**」，随后给出写法建议「**积层膜膜（ABF膜）**」。**该写法本身即演示**——「积层膜膜」四字放在中文里重复一眼可见，而「ABF 膜」看起来毫无问题。
- 顺此查出成体系的现象：技术缩写多为「修饰语＋中心词」结构，**缩写本身已含中心词**，中文再缀一次即冗余。Doctor 点的四个词**全部中招**：ABF（Film）、CCL（Laminate）、HBM（Memory）、CPO（Co-Packaged）；同族还有 PCB、DRAM、SSD、TSV、LED。
- 落 `permanent/中文表述语域规范.md` 新增「缩写与中心词」节：九词对照表 + **双重冗余提醒**（「味之素 ABF 膜」错两处：Ajinomoto 与 Film 都已在 ABF 内）+ 自查法（**把缩写在心里展开成中文，重复即刻可见**）+ 知识库建节点时「名称与描述的物种必须一致」。

### 二 · 渊图批一：节点名去冗余（16 个 · update-only）

- 扫全图命中 16 个 name 带冗余的节点。patch `_v3_20260729_节点名去冗余_manual.json`，**只改 name、不动 id / edges / description 正文**，计数守恒 3554/4061，16 个全 `took_patch`。
- 几处处理值得记：
  - `concept_ABFFilmSupplyMonopoly` **用中文全称「味之素积层膜供应垄断」而非缩写**——单写「ABF 供应垄断」会产生新歧义（读者分不清膜还是载板），**去冗余的同时消歧义**。
  - `metric_ProsperityScore_CPO` 原名「CPO共封装光学景气分」是**同一个词中英各说一遍**，改按新规范「共封装光学（CPO）景气分」。
  - **`IC 载板` 保留不动**——`IC = Integrated Circuit`，Carrier/Substrate 不在缩写内，**不构成冗余**。这条要区分清楚，否则矫枉过正。
  - 每个改名在 props 留 `_rename_20260729` 记录原名。

### 三 · 渊图批二：正文清理（82 处 · 定向修复脚本）

### 四 · ★ 险些自造 71 个 provenance 幽灵（本场最重要的一笔）

- dry-run 报「全文残留 112 处」，而限定字段扫描只有 105 处——**112 > 105 这个矛盾本身无害，但顺着查下去才发现范围里混着 71 处真实文件名**：`data_sources.file` 里的 `2026.04.30-帕米尔研究：头部PCB板厂ABF载板业务进度调研.md`。
- **若照着「112 处未清」去补刀，就会一次性制造 71 个 provenance 幽灵**——正是渊图 `ERR-20260718-001` 记录的坑（LLM 篡改 `data_sources.file` 致溯源链断裂，且「分裂型污染比全错更难查」）。那次是 LLM 犯的，这次差点由我用批量替换主动犯一遍。
- 最终确认：脚本只扫 `description` / `desc` / `properties` / `evidence`，**天然避开**文件名、留痕、别名、嵌套 patch 结构，82 处正是该改的全集，112 处残留**全部应当保留**。

## 做出的决策

| 决策 | 原因 | 影响 |
|------|------|------|
| **缩写规范立为硬约束**（技术输出与知识库建设） | 四个词全中不是巧合——技术缩写普遍是「修饰语＋中心词」结构 | 落 `中文表述语域规范.md`；going-forward 生效 |
| **自查法定为「展开成中文」** 而非「记住 F 是 Film」 | 靠记忆会漏，靠展开则**冗余自动可见**。英文写 `ABF Film` 一眼知重，中文写「ABF 膜」看不出 | 规则的核心机制是**让错误自己浮出来**，不依赖使用者的知识储备 |
| 节点名改名**只动 name、不动 id** | id 用英文本就不重复（`ABFFilm` 无冗余）；改 id 会断边 | 冗余只发生在中文 name 上——这本身印证了规范的必要性 |
| **`data_sources.file` 绝不清理** | 改了断溯源链，等于自造 provenance 幽灵 | 清理脚本扫描范围严格限定在正文四字段 |
| **`aliases` 不清理** | 别名的职责就是**覆盖俗称**，「国产ABF膜」正是人们会输入的检索词，清了反而匹配不上 | 规范只管"我怎么写"，不管"别人怎么搜" |
| **`_rename_*` / `_meta.*.reason` 留痕不清理** | 内容就是「原名「ABF膜供应垄断」」，清了等于抹掉自己刚做的审计 | — |
| **「DRAM 内存池」不改** | memory pooling 是专有概念、中心词是「池」，DRAM 只是限定词；改成「DRAM 池」反而不通 | 立「专有概念优先于机械规则」，脚本用占位符保护 |
| 把「存量清理四类边界」也补进规范 | **写作规范管未来的输出，清理规则要面对存量的异质性**——同一个「ABF膜」在四类字段里处置完全不同 | 规范新增第二节，含四类表 + 「数对不上先查清楚」方法 |
