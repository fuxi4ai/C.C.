### Q3 · `scope_guard.sh` 是否如声称工作

**自检**：`SCOPE_GUARD_DIR=<自建>` 下 `--self-test` 4/4 通过（rc 0）。四检内容与代码相符，但**第 2 检的打印「且退出码为 1」并未被真正断言**（只 grep 了文本）——退出码 1 由我另行实测为真。

**计数实测**（`SCOPE_GUARD_DIR=/tmp/audit_2/sg`，避开共享路径）：

| 情形 | 实测输出 | 判 |
|---|---|---|
| 原地改 2 行 | `增行 2 · 删行 2` | 合（但「改动行数」＝4 个 diff 行） |
| 原地改 3 行 | `增行 3 · 删行 3` | 合（同上） |
| 纯新增 2 行 | `增行 2 · 删行 0` | 合 |
| **删 1 条 `- 待办丙`** | `增行 0 · 删行 0` | ❌ **错**（原始 diff 明明打了 `-- 待办丙`） |
| **整块删 3 条 `- ` 行** | `增行 0 · 删行 0` | ❌ **错**（3 行删除报 0） |
| **改 `- 甲`→`- 甲改`** | `增行 1 · 删行 0` | ❌ 不对称 |
| **新增 `+ 新增条目`** | `增行 0 · 删行 0` | ❌ 错 |

根因：`grep -c '^+[^+]'` / `grep -c '^-[^-]'`（`:57-58`）用「第二个字符不是同符号」来剔除 diff 头，**把「内容本身以 `+`/`-` 起首的行」一并剔掉了**。暴露面：目标件 `Projects/PEC/GOTCHAS.md` 有 **218** 行以 `- ` 起首（全件 1640）、`brain/PEC/architecture/决策记录.md` **632** 行（全件 2555）、`Projects/PEC/CLAUDE.md` 50 行（全件 386）。
**判据可行性**：脚本只**印**判据文本，从不计算/比对；且输出是两个数（增、删）而非一个「改动行数」⇒ 对「原地改 2 行」到底是「2=2 过」还是「4≠2 超」，脚本不定义。这与它的「提示器」自陈一致，属**声称（给出判据）> 实装（不判）**的小落差。

**共享快照目录（已知坑）——本沙箱里它已被占住，且不止一种后果**：

- 事实：`/tmp/.scope_guard` 现为 **`nobody:nogroup` 所有**（2026-10-01 20:38 建），内含他人 `.bak`。**默认路径在当前会话已不可用**。
- 实跑（不设 `SCOPE_GUARD_DIR`）：`snap` → `cp: … Permission denied` ＋ `scope_guard: 快照失败（挂载怪癖？试新建+mv）`，**rc=2**；`chk` → `无快照`，**rc=2**。⇒ **fail-closed 属实，不静默**（此判据过）。
- 但两处瑕疵：① 诊断**误导**——明明是「目录被他人占住/不可写」，提示却指向「挂载怪癖？试新建+mv」（照做无用）；`mkdir -p "$SNAPDIR"`（`:36`）本身**未查返回码**，靠随后 `cp` 兜底。② **若占位者留下的同名基线可读（如 555 目录），`chk` 会静默拿别人的基线比**：实测 `chk` 对自己的文件报出 `-这是别人的同名快照内容 / +我自己文件的真内容` 并 **rc=0**——不静默「绿」，但会**静默给出错误的改动面**。
- **同 basename 撞车**（默认共享、且 `SNAPDIR` 只按 basename 键控）：`p1/todo.md` 与 `p2/todo.md` 用同 tag 时，后者静默覆盖前者快照；对**未做任何修改**的 `p1/todo.md` 跑 `chk` 报 `增行 1 · 删行 1`（实测）。目标件里 `GOTCHAS.md`/`CLAUDE.md`/`PRD.md` 正是重名大户。
- `SCOPE_GUARD_DIR` 这个逃生阀**只在 `:29` 与自检里出现，`--help`（USAGE 段）与文件头只字未提**（grep 计数：USAGE 段 0 次）——正文对「快照落 /tmp」的说明也没提共享路径风险。

**退出码实测**：有改动 → `0`；零改动 → `1`（并打「请核实目标文件是否搞对」）；无快照/无文件 → `2`。与代码一致。

**「拦不住 Edit 工具」核实（只读代码，未真试）**：**属实**。该件是纯手动 CLI，无守护、无 hook、无 wrapper；实查 `brain/.hooks/settings.snippet.json` 只挂 `SessionStart`/`PreCompact`/`Stop` 三事件，**无 `PreToolUse`**，且全库 grep `scope_guard` 只命中 md 文档与自身，**无任何配置引用它**。

**B. `scope_guard.sh`**
