# PRD · 真相层（原始会话）· C 档

## §一 · 任务目标

brain 的最底层是 /save 写的摘要日志，本身就是「笔记」，没有可以对照纠错的原始记录。Anthropic《The components of agent memory》（2026-11-06）把原始记录（transcripts）定为整个记忆层级的地基，dream 的核心动作是「用原始记录核对笔记」。另外 Claude Code 默认只保留 30 天记录，2026-08～10 月的原始记录已基本被清掉（实测 10 月剩 4MB、8 月约 0）。本任务建真相层：把原始记录按 C 档抽取成 brain 自有、跨模型可读、脱敏、不进 git 的长期库，并提供检索入口，作为后续 dream 轻档的数据底座。

C 档＝对话文字 + 工具调用参数 + 工具结果（每条截前 2KB）。实测抽取 75.8MB / gzip 25.7MB（2026-11-01～20 的 463 个文件）。

**Doctor 原始指令**(逐字引用):
> "1、建立真相层可以，但是会很占空间吧？"
> 选择窗回答：「C档：对话+工具」

**任务规模估算**:
- 预计涉及文件数: 新建 2～3 个（抽取器、检索、测试），改 2 个（.gitignore、chats/README.md）
- 预计耗时: 1～2 小时
- 涉及项目: brain（记忆系统）

既有工具 `.tools/import-chats.py`（2026-05-14）只留文字、工具归约为占位，按文件名去重（续写的会话不会更新），无脱敏，输出进 git 跟踪的 `chats/code/`，实际只导过 1 篇。与 C 档要求差距大，本任务新建工具，旧工具保留不动。
