# PRD · GAI升级文件系统健康度管理

## §一 · 任务目标

**动机**：GAI（海螺姑娘 · 全局资产看板，artifact `global-asset-inventory`）当前是「资产盘点 + 五态发光 + 修复指令生成」的看板。它能回答「哪个库陈旧、哪个项目错题本积压几条、TODO 几条」，但回答不了「哪个项目整体更糟、糟到什么程度、这周比上周好了还是坏了、班次跑得准不准时」，也不能在详情页直接把能安全做的事做掉。Doctor 要把它正式升格为**文件系统健康度管理项目**：各项目有可排序的健康度分与运行效率分，二级详情页有分档的一键优化。

**范围**（2026-11-06 AskUserQuestion 四题 · 均取推荐项）：
- 评分维度：五维加权 0-100（新鲜度 30 / 自检结果 25 / 治理积压 20 / 陈旧文件 15 / 工作文件齐备 10），不适用维度按剩余权重归一，分级 A≥85 / B≥70 / C≥50 / D。
- 运行效率：三指标分步点亮——① 产出时效（现有数据可算）② 失败率（需运行历史）③ 脚本耗时（需新埋点）；未埋点显示「未记录」，不填零。
- 一键优化：三档——自动档（只读诊断、幂等刷新）/ 确认档（可回滚的写操作，Doctor 批一次后执行）/ 禁手档（只贴命令）。
- 分期：三期各自验收。一期＝健康度评分 + 看板展示 + 定位升级；二期＝运行效率（埋点契约 v2 派工 + 评分）；三期＝一键优化三档面板。

**Doctor 原始指令**（逐字引用 · 由 EAL gate 场转述）：
> "GAI 这个项目能否进行一次升级，正式作为文件系统健康度管理项目。除了现在的数据库是否陈旧、Gotchas、todo 统计功能外，升级为各项目健康度、运行效率评分的功能，并继承在二级详情页一键优化的能力。先写 PRD。"

四题答复（2026-11-06 03:22 PST AskUserQuestion）：评分维度「五维加权 0-100（推荐）」；效率定义「三指标·分步点亮（推荐）」；一键优化边界「三档分级（推荐）」；分期「三期各自验收（推荐）」。

**任务规模估算**（推断）：
- 一期：改 2 件（`conch_engine.py` survey 段、`dashboard/build_asset_dashboard.py`）+ 新建 1 件（`dashboard/HEALTH_SCORE_SPEC.md`）+ 改 manifest schema（`schema_version` 1.0→1.1，纯增字段）+ 改 3 处定位文案（brain 系统概览 / 项目总览行 / 看板页脚）；约 3 小时 + dry-run 对拍 1 小时。

- 三期：build 详情页三档面板 + 动作执行脚本 `dashboard/optimize_actions.py`（白名单 + 审计 + 回滚）+ Cowork 侧班 prompt 变更（调度变更 · 走 Doctor）；约 5 小时。
