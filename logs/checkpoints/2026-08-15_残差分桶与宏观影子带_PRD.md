# PRD · EAL 残差分桶与宏观影子带

## §一 · 任务目标

**动机**：① EAL 残差告警已失去判别力——十三日 +5.37pp 的缺口里混着两种根本不同的东西：「事件带缺席」（量级带空导致无法记账）与「非事件漂移」（AI 慢牛趋势·平凡日/纪录日上涨，本就不属事件归因射程）。纪录日无事件也红、每涨一天缺口机械扩大，告警的「疑漏因子」语义已被稀释。② 宏观驱动因「无净样本→带永远留空」死锁——等待是被动的，样本积累没有机制。

**做法**（Doctor 2026-08-15 裁「2+3」组合）：**残差分桶**——残差日增按「事件日/平凡日」拆账：事件日桶＝带缺席（告警阈值只读此桶）、平凡日桶＝非事件漂移（只记账不告警）；总残差照旧展示。**宏观驱动影子带**——影子锚 +0.3~+0.8pp/次（只影子记账不进方程），顶级披露日强制产影子读数，@利率重估影子阈 4bp（正式 6bp 不动）。恒等式/Σ/正式带全不动。

**Doctor 原始指令**（逐字引用）：
> 「新的因子/模型修正方案有么？」→ CC 提案五条 → Doctor：「2 + 3」→ 对齐三问：告警阈值切事件日桶（Doctor 批推荐）· 三级事件日定义（Doctor 批推荐）→ 对齐结论 Doctor「同意」→「开工」。

**对齐结论摘要**：
- 核心需求：告警恢复判别力 + 宏观驱动样本主动积累
- 事件日三级定义：注册因子触发日／顶级披露日（含候选轮证伪）／geo 新触发或实质升级日；其余平凡（纪录日归平凡）；单股杂质日不算事件日（杂质已进 Σ）
- 告警口径：阈值判定切事件日桶；平凡日桶只记账；总残差照展示
- 版本：规则书 v1.4 → **v1.4.1**
- 影子锚：+0.3~+0.8pp/次（不进方程）；@利率重估影子阈 4bp
- 起草期修订一处（已 Doctor 批准随开工）：值守班 prompt 仅改告警卡/因子拾遗卡条款两处（判定口径切事件日桶），其余不动

**任务规模估算**：
- 涉及文件数：4（台账 md · artifact HTML · 值守班 prompt · PRD 本体）
- 实际耗时：约 1 小时
- 涉及项目：剑酒青丘（EAL）单项目
