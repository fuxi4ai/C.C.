## 完成的工作

### 点单入口两缺口硬化（VV 首测拦获 · bundle 内单件落位）
- **跨 shell 参数破坏根治**：`-AuthorB64` 作命令行参数经 zsh→OpenSSH→PS 仍被解析破坏 → `harvest_one.ps1` 加 `-Stdin`（`[Console]::InputEncoding=UTF8` 读 stdin 一行 JSON）；Mac wrapper `dva-order.sh`（python3 构造 JSON | ssh stdin）——**stdin 是纯字节流，不经任何一层 shell 参数解析**，三层引号问题物理消失。实测中文昵称通过。
- **PS 5.1 NativeCommandError 根治**：native 进程 stderr 经 `*>&1` 被包装成 ErrorRecord，`EAP=Stop` 下升级为终止错误（Playwright warning 即击穿）→ node 调用改 **`cmd /c "... 2>&1"` 包裹**（stderr 在 cmd 层合并·PS 只见纯 stdout）+ 局部 `EAP=Continue` + `$LASTEXITCODE` 唯一真相。run_refill 同型预修（赶在首班前落位）。
- VV 实测：中文 stdin JSON、stderr 合流、点单 limit=1 全过。

## 做出的决策

| 决策 | 原因 | 影响 |
|------|------|------|
| 跨机点单通道＝stdin JSON（弃命令行参数） | 三层 shell 引号/编码无解，stdin 字节流零解析 | order/analyze 两入口同通道·未来跨机传参范式 |
| native 调用一律 cmd /c 包裹（PS5.1） | stderr→ErrorRecord→Stop 升级击穿是机制性的 | 三个 ps1 入口统一防线·首班免疫 Playwright warning |
| 告警三桶（known-noise 单列不定级） | 全算 WARNING 则每班假红、真告警被淹；不算则假绿 | 首班读法：other=0 且 exit=0 才真绿·orphan≈630 正常 |
| 分析层迁移即时做、定时任务不注册 | 主链 env 就绪改动小；分析是内容驱动非日历驱动 | 手工点单可用·事件驱动留观察期后 |
| Mac 旅行模式＝只分析（Doctor 两次简化） | 出行下载没必要，回家 fuxi 自然补——归整问题整体消失 | 单写零例外·Phase 7 退役取消 |
