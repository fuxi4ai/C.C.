# 会话日志 — 2026-08-13

**项目**：星空（渊图星空常驻 artifact）
**主题**：UI 显隐持久化 + 全景看点折叠坞五轮迭代定稿 + 搜索框定位 + 引力/材料分布核实

## 完成的工作

- **UI 显隐持久化**：localStorage key `starry-ui-hidden`（'1' 隐/'0' 显），首开无记忆**默认隐藏**（Doctor 中途改判），隐藏/Esc/显示UI 同步写状态，全程 try/catch 降级。Cowork artifact 的 localStorage 跨 app 重启持久（工具文档口径）
- **全景看点卡右侧折叠坞（五轮迭代终版）**：默认全隐、仅留 8px 隐形悬浮带（右缘 44px 处、与卡同高）；悬浮展开（0.38s）；**打开后热区加宽至卡右缘→屏幕右缘 44px**（收合线区域不收起，只有移出卡+收合线区域才收起）；点星常开（`.expanded`）、Esc/重置退出回折；UI 隐藏模式热区失效。实现 = JS 状态机（mouseenter/leave 标记 → `body.info-open`）+ 独立元素 `#info-edgezone`（JS 同步其高度=卡 offsetHeight）
- **搜索框定位**：底部胶囊左缘 `calc(50% - 192px)`（搜索框中心 50%−74px——先按令居中、再按令回移一半），三按钮随胶囊同步
- **引力设置原则核实**（Doctor 问「最初的原则」）：FR 变体——引力∝r²/k 仅作用于有边节点对、按边权重加权、跨桶×0.05；同桶斥力×0.30、异桶×1.0；community_pull 0.55、inter_strength 180、k=(320³/N)^(1/3)；v1→v3 参数演变（k 200→320、radius 200→400 等）→ Doctor 裁「保持现状」
- **紫色材料系分散核实**（Doctor 问「是否因材料与各星团相关性」）：全量数据实证——材料本体 95 个、散布半径 184≈全图 197；89% 边连外部（半导体 31%/光通信 13%/AI 5%）、材料互连仅 35 条；27 个材料节点比紫桶质心更贴近其服务行业团（光通信材料贴得最紧，−130 多）→ **「材料被各行业共享」是根因、数据语义正确反映，非 bug** → Doctor 裁「不改，只核实」
- 全部改动**两文件同步**（`Claude/Projects/星空/prototypes/starscape-template.html` 模板 + `AI4ME/渊图-outputs/yuantu-starry-skies-v3-full.html` 真源）→ cp 到 outputs → update_artifact 推送；`.bak_20260813-*` 备份链（uiPersist/highlightsDock/V1-V4/searchCenter/searchCenterHalf）全程留痕
- 落盘收尾：auto-memory `project_yuantu_starry_artifact.md` 已更新为定稿状态（含 GOTCHAS 两条新坑）

## 做出的决策

| 决策 | 原因 | 影响 |
|------|------|------|
| 折叠坞五轮迭代定稿（收起全隐 8px 带原位 → 打开后热区加宽 44px） | 历次反馈逐轮修正；冷区根因 = `#info` 的 overflow-y:auto 连带裁剪卡外伪元素 | JS 状态机 + 独立 edgezone 元素，弃 CSS hover 链 |
| UI 显隐首开默认隐藏 | Doctor 中途改判（先选「首开显示」后改「默认隐藏」） | 无记忆时隐藏；显式显示才记 '0' |
| 搜索框中心 50%−74px | Doctor 令「居中」后又令「回移一半」 | 胶囊 left=50%−192px，注释写明算法来源 |
| 引力参数与材料分布保持现状 | 核实为数据语义正确反映；引力单参数不可独调（∝r² 与 ∝k²/r 不对称） | 不改 |
| 材料相关节点按行业关键词散落（AXT→光通信、FR4 覆铜板→半导体等） | 分类规则：材料本体强制紫色桶、相关公司/概念按关键词 | 接受现状 |
