# 自发现迭代

三问的第三问服务于研究质量改善，不用于制造新门禁或替预测失败找理由。保持两条轨道：**标的待验证信息**改变本案判断；**方法候选**改变未来怎样研究。信息未知本身不是方法缺陷。

## 每次研究

开始增量研究时，按标的定位上次正式报告，回读尚有效的验证触发器与方法候选。逐项判断触发/未触发/证据不足/不再适用；不把未触发留成永久 TODO，不把找到事后信息当旧预测已成功。

涉及市场计价判断时，保留前次主题/期限、消息前基线、公开与传播时点、已发生价格反应、叙事状态、下一观察点及剩余预期差；使用估值时再保留隐含门槛和假设。回访分开评估经营兑现、信息增量与价格实现，检查传播、风险溢价及同期事件；不能只因后来涨跌吻合，就把“计价不足/过度”标为已验证，也不能重复使用已经兑现的催化。

对首选动作与风险概率，保留预测时的信息集、事件定义、期限、概率区间/代表值、依据和改判阈值；到期按原定义核结果，未到期或无法判定不算预测失败。检查是否漏查当时可得的决定性材料、是否选出了相对占优动作，并区分事件预测正确与投资回报正确。单例命中不证明概率校准，单例失败也不自动否定一个事前合理的低概率情景；新证据应更新判断，不倒改原概率。

在第三问中只保留有实质价值的候选，写清：

- 发现：本轮哪项真实遗漏、错误或歧义会改变判断，证据在哪里。
- 修订：最小可复用规则或资源改进，适用对象与不适用对象。
- 验证：下一次用什么正例、反例或独立来源检验；怎样算失败。
- 状态：candidate / tested / independently_verified / outcome_observed；未实际发生的阶段不晋升。
- 退役：何时合并进现有规则、缩小范围或删除，避免规则无界累积。

报告落盘时将这些信息放在该报告尾部，连到前次报告；不另外制造重复日志。纯对话研究在回答中保留，不自动修改长期记忆或 skill。Doctor 请求保存、固化或修改方法时，才按相应授权维护。当前授权任务中的确定性修复可以直接完成；外部研究源及评分库仍只读。

## 维护 skill 时

先复现实际缺陷，再改最小范围，使用未参与实施的 agent 做独立前向试跑：仅提供技能、真实请求和必要原始材料，不给标准答案。至少一个适用案例和一个边界/反例，观察是否实际追查决定性材料、给出首选及概率依据，并能在高胜率但回报不利或证据相反时改变动作；高风险读取器补非法输入测试并在普通与 Python `-O` 模式检查错误族与非零退出。结构验证器通过不代表研究质量通过。

涉及边际信息修订时，前向样例覆盖结构基线未变但新闻冲击已被交易，以及新消息确实改变经济影响的相邻场景。检验是否区分终局与边际、反应速度与充分性，是否给出叙事及下一观察点，并保留行动排序、执行条件和风险概率。可用显式合成材料做离线行为测试，不能冒充实盘或证明收益；不以匹配措辞替代验收。

只有行为改善有证据、且未破坏相邻场景，才晋升为规则；单例涨跌不能证明投资方法有效。研究方法的正确应用可以被验收，投资结果要等真实观察，不能以报告已生成替代。保留旧报告和原先信息集，修订状态写在新报告/维护记录，不倒签。
