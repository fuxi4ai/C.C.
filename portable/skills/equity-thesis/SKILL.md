# 个股定性研究

回答：**查深关键事项后，当前哪项行动最值得采取，凭什么胜出，市场错在何处，反向风险有多大概率？** 必须给出有排序的首选动作，不以多空并列或“保持关注”替代判断。胜出指在明确价格、期限和假设下相对其他动作更有优势，不承诺投资必胜；方向由证据决定，不预设看多、看空或等待。中文称 Doctor / 您。

研究主线是 **最近发生什么 → 相对消息前预期新增什么 → 市场计价多少 → 叙事处于什么状态 → 下一个观察点 → 剩余预期差对应什么行动**。四项状态判断补充而不取代经营、估值、龙鱼对照、行动策略与风险概率。不要求精准预测终局；也不把正式裁定、完全确定或完整估值模型作为判断边际消息和叙事状态的前置门槛。

## 启动与边界

- 确认公司全称、交易所、证券代码、股份类别、交易币种及研究截止时间（含时区）。同名或多地上市会影响结论时先核身份。用户未给窗口时，用最近七个自然日梳理新增信息，并回溯解释所需的财报与产业背景；明确起止日期和最新已完成交易日。
- **每次触发都实际搜索该标的最新市场信息**，包括最新公司/交易所披露、相关竞争或客户动态，以及与公司敞口有关的宏观变量。使用可用 web 工具；搜索结果用于发现，影响判断的事实必须打开原始来源。记录查询范围、读取时间和未覆盖部分。不能用历史报告、缓存、文件 mtime 或“无搜索命中”替代本次核验。
- **把检索深度集中到会改变首选动作的关键事项。** 对每项打通事件原文、支持/反对方实际诉求、执行能力与经济约束、价格影响；不得只核新闻表面就下结论，也不让不影响动作的程序细节挤占决定性问题。按 [methodology.md](references/methodology.md) 的关键事项检索闭环执行。
- 搜索不可用，或 Doctor 明确限定离线材料时，完成仍有价值的历史/条件式分析，醒目标明“最新信息未核”；没有可靠价格则不评价当前买入价，不虚构已完成最新检索。不要把检索失败冒充没有新事件。
- 本 skill 默认只读研究。可读取下列资源；不得运行 CC/渊图/风险日报刷新、入库、评分、发布或调度脚本，不改评分库，不据此下单或发送给第三方。报告落盘遵循当前任务授权。
- 开始复杂分析时，定向召回 Codex Brain 经验索引和命中正文，报告实际采用的 ID；不要为形式全量读库。资源位置和读取合同见 [resources.md](references/resources.md)。

## 研究流程

1. **先建基线，再找增量。** 用本次回读的最新财报与关键披露解释公司卖什么、利润/现金来自哪里、成长业务处于哪一阶段。逐条以消息前的市场预期为基准，区分事实新增、政策意图/可信度变化、旧事重述、新验证和注意力/情绪传播；结构判断不变不等于没有边际利好或利空。阅读 [methodology.md](references/methodology.md)，按对象选用深入模块。
2. **拆解真正改变判断的断言。** 为关键论点保留“事实/计算/具名观点/推断/情景”、来源与定位、发表/事件/观察时间、期间、单位、原文范围、反证及核验状态。官方自测不等于独立测试；转载同一稿件不增加独立证据。冲突未解决时并列呈现，不能取平均消除冲突。
3. **连接宏观、行业和公司。** 沿“事件新增信息 → 相对真实事前基准的差异 → 公司经营敞口 → 收入/利润/现金流/资本成本 → 中间验证 → 抵消因素”推演。风险卡的证据、定价、情景状态各自保留；风险颜色或优先级不能转成 alpha。无可靠传导路径则说明弱相关，不强套宏观故事。
4. **检验竞争与商业化。** 比较产品层级、客户选型、替代路线、议价能力、交付与回款。市场规模和市占必须展开分母。研发、测试、导入、订单、交付、收入分别陈述；按照行业调整里程碑，不能以缺少硬件订单标准否定银行或成熟消费公司。
5. **先判断计价进度与叙事状态。** 阅读 [market-pricing.md](references/market-pricing.md)，先回读消息前基线、首次公开与集中传播时间、第一可交易窗口及后续相对反应。对主要信息给出正在计价、首轮反应明显、较充分/透支、部分计价或无法识别等有依据的判断，允许定性，不强造计价百分比。区分迅速反应、合理程度和反应持续性；分别说明基本面叙事与短期交易叙事，指出正在强化、受质疑、修复、兑现或切换及其证据。
6. **检验剩余空间与下一观察点。** 核股价时间、股数与稀释、币种、现金债务及财报期间，再按业务选择估值方法，以可复算情景或反向估值检验剩余行动优势。不用亏损 PE 或无出处目标价，不从涨跌幅倒推未计价。已兑现影响进入现价基线，不重复列作未来催化。观察点选下一条可能改变预期的消息、客户行为或结构变化，写来源、时间窗/事件条件、何种结果会改变叙事和动作；没有可靠日历就用事件条件，不把意见截止日当裁定日。保留大盘/行业、风险补偿与同期事件解释。
7. **与龙鱼六维分对照。** 用下述只读工具读取目标 record，按 scorer 分别展示日期、口径和覆盖情况。龙鱼包含模型判断和财务锚点，不是纯客观量化。解释同向/分歧来自新证据、时间、范围、口径还是合理观点差异；不平均双 scorer、不另造总分、不机械重复扣分。没有评分或分数陈旧时，继续研究并明确缺口。
8. **选出胜出动作并承担判断。** 比较适用的买入/增持、持有、减持/退出、不买或有条件等待，先给唯一首选及其相对优势，再说明价格条件、研究期限、催化与失效触发。持有建议区分已持仓和新资金，不臆测 Doctor 持仓；比例、杠杆和组合退出另需目标约束。关键事实不足先补查，不能把“尚未完全确定”当作保持中性的理由；若交易优势不成立，明确选不买/减持或条件等待并解释机会成本，不伪造正收益机会。概率及动作比较见 [methodology.md](references/methodology.md)。

## 输出与三问

主文按 **胜出观点与首选动作 → 最近事件及边际增量 → 市场已计价程度与剩余预期差 → 当前叙事状态 → 下一观察点 → 执行策略和备选排序 → 带概率的反向风险** 展开；可合并紧密相关的段落，语义不可遗漏。执行策略写适用持仓/新资金、价格与期限、触发和失效条件；必要前提随结论披露。风险不占据开篇，不与主判断等权堆叠。每个实质性反向风险写明事件、期限、主观概率区间或已核概率测度、依据、潜在影响及改判动作；无法解释的数字不得编造，事件概率不等于股价涨跌概率。

经营与产业逻辑、宏观传导、估值、龙鱼对照用于支撑上述判断，按重要性展开。**“市场已计价什么、是否充分”必须独立呈现**，注明对象/期限、证据、边界及剩余预期差；个别净价格贡献无法识别不妨碍判断消息方向、叙事状态或选动作。广泛传播的显著消息先检验一阶冲击是否已被迅速交易，声称仍有机会需要增量依据；不预设市场总能立即充分计价，也不默认情绪反应必然反转。长研究可附断言表和来源清单。

**报告尾部必须依次、独立回答三问；不能仅列问句或将第三问并入风险免责声明。**

1. **核过没有？** 列出本轮实际回读的一手证据、时点与已复算项目；明确哪些是历史资料、未核、缺失、不可比或推断。不用“全核”概括混合状态。
2. **有什么隐患？** 按概率和损失对反向风险排序，交代概率口径、期限、具体失败路径、影响和改判触发；结合情景依赖，不能将重叠风险概率直接相加。不套泛泛“市场有风险”，也不以无依据百分比完成格式。
3. **有什么可以进化的地方？** 找出本案暴露的方法缺口，提出最小修订、验证办法及适用/退役条件；区分“下次补一个数据”与“可复用的方法进化”。有已验证改进才说明证据，没发现则如实写“本轮暂无足以晋升为通用规则的新证据”。按 [evolution.md](references/evolution.md) 保持跨次可追溯，禁止为交差制造规则。

## 收尾校验

对左右结论的数字检查身份、期间、单位、有限值、计算链和来源；未知不相等。核对关键事项是否查到真正改变动作的证据、首选是否胜过适用备选、概率依据是否解释得通。检查最强反证是否真的否定当前假设，而不只是存在另一条路线。若使用历史类比，保留失败、无反应、重叠事件和事后信息限制。复杂或高风险结论交由未参与研究的 subagent 从实际来源重放，修复具体缺陷后交付。
