## 三 · 将来回切：Kimi store → Cowork store（⚠ 方向不可反）

> 场景：Kimi 壳用了段时间，班的 prompt 有更新（在 Kimi 侧 update_scheduled_task 改的），Doctor 决定回切 Cowork 做主。

```bash
# ⚠ 源 = Kimi store，目的 = Cowork store。反了会用旧文件毁掉新 prompt。
# 先 dry-run 看清单（-n 不实写）：
rsync -avn --delete \
  "/Users/lunarabbit/Gateway-workspace/Scheduled/" \
  "/Users/lunarabbit/Claude's workspace/Scheduled/"
# 确认清单只有预期内的班（19 个 + 可能的 .bak），去掉 -n 实跑：
rsync -av --delete \
  "/Users/lunarabbit/Gateway-workspace/Scheduled/" \
  "/Users/lunarabbit/Claude's workspace/Scheduled/"
```

- `--delete` 语义：Cowork store 里多出的班（Kimi 侧没有的）会被删——**实跑前核对 dry-run 清单**，若有想留的（如 `_archived/`），先搬走或加 `--exclude='_archived/'`。
- 回切后：Cowork 侧 `update_scheduled_task(enabled=true)` 恢复 19 班，Kimi 壳侧对应 disable（角色对调，同样防双跑）。
- artifacts 同理会已经在 Kimi 壳 store（`~/Gateway-workspace/Artifacts/`）里更新——Cowork artifact 目录在 workspace 树，**artifact 的更新不走本卡**（update_artifact 是注册表操作，回切 Cowork 后由各班首跑自然刷回）。

## 四 · 字节级终封（B1 残余 · 迁移正确性的最后一道）

本壳 store 受应用保护（沙箱/CC 均不可读——**保护跟随 store**，2026-08-02 迁 `~/Gateway-workspace/` 后实测依旧），19 班 prompt 的字节级核对只能在终端做：

```bash
cd ~/Documents/Claude/brain/references/scheduled-live-mirror
for d in live/*/; do
  t=$(basename "$d")
  [ "$t" = "_archived" ] || [ "$t" = "handshake-consumer-daily" ] && continue
  diff <(awk 'BEGIN{f=0}/^---$/{f++;next}f>=2' "$d/SKILL.md") \
       <(awk 'BEGIN{f=0}/^---$/{f++;next}f>=2' "$HOME/Gateway-workspace/Scheduled/$t/SKILL.md") >/dev/null \
    && echo "OK   $t" || echo "DIFF $t"
done
```

**预期**：18 行 `OK` + 1 行 `DIFF longyu-weekly-dualscorer`（唯一刻意偏离 = F2 口径切换注记，PRD §五 偏离 #1）。出现其它 DIFF = 迁建有变异，拿 diff 详情找 CC。
**2026-08-02 终封实绩**：首跑 18 OK + 2 DIFF（longyu 预期内 + touzhijunjun 两处漂移：缺 subagent 并行段、缺末尾换行）——touzhijunjun 已经 update_scheduled_task 按镜像全文修正；longyu 的 DIFF 由「F2 注记（刻意）+ 步骤2/3 路径未同步 08-01 修复（疏漏）」两部分组成，路径疏漏由 Doctor 终端 sed 补改后，DIFF 应只剩 F2 注记。
