## 关键规则

- **落盘后自动同步本概览**（2026-08-10 Doctor 定 · 对齐渊图）：每次改动库结构 / 真源裁定 / 引擎或弹性口径等「结构事实」落盘后，CC **自动**更新本概览「最后更新」+ 受影响的「当前数字」「关键规则」行，**不再单独询问**；易变周更量（标的/六维/鲜价）仍由当周周报承载、不在此同步。
- **数据真实性铁律**（2026-06-12 老师定）：没有新鲜价格，**宁愿留空也不造假**；用过期/旧价必须标注具体时点 + 已过天数（>30 天加「过期」标记）；缺数留「待核验」、占位禁入；**同比为准、环比参考**；信源分级 P0 期货 / P1 权威站 / P2 web；web/特气补价须带 `confidence%` + `asof` + 新鲜度。
- **价格状态三态**（2026-06-12）：**鲜价**（本体现货 P0/P1）→ **代理价**（P1 代理序列·金色标签·判据=有结构化涨幅 `yoy/yoy_ref/mom_ref`）→ **待核验**（无价）。代理价不混入鲜价；严格 yoy（旧价口径）才入弹性，参考值不入。
- **领域分库契约**（2026-06-29）：**白泽库 `business_breakdown.db`＝大宗涨价受益真源**（owner 白泽唯一写，真源表 `benefit_relations`）；**龙鱼库＝公司级真源**（六维实时读龙鱼库，不再本地镜像）；`stock_scores` 冻结弃用。
- **单库单一真源路径**（2026-06-15）：白泽所有 DB 读写统一到宏观库 `business_breakdown.db`，路径只认 `lib_paths.BUSINESS_DB`；项目本地 `data/business_breakdown.db` 已归档 `data/archived/`。
- **产物归集**：最终报告/看板 → `~/Documents/AI4ME/白泽大宗-outputs/`；中间产物 → 项目 `reports/`；周报 md → 项目 `周报/白泽周报_最新.md`（单份滚动每周覆盖）。
- **弹性 v2 口径**：弹性分＝相对排序分、**非利润预测**，禁用「净利润增幅」表述；旧 CSV（涨价商品库·冻结 04-10）弃用于弹性。
- **观星＝独立模块不进周报**（2026-06-23 裁定）：Fed 预测（`GuanxingPredictor`）按设计不进大宗周报，主路径根本不碰它。
- **沙箱红线**：沙箱挂载盘**禁直写 SQLite/删文件**（报 `disk I/O error`，GOTCHA-027/028）→ 一切写库/改库脚本**必须在 Mac 原生终端跑**（沙箱测试用 `--db` 指 /tmp 副本）。
- **`_health.json` 每晚重生成**：它是 `weekly_health.py` 的 `legacy` 字典整段重建的产物，**手改输出当晚被冲回**；要持久登记（如 deprecated 表）须改生成器源码，不改 JSON（2026-08-09 P1 实例）。
